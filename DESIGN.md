# AI-Native Bootcamp — дизайн-код «MINIMAL STEEL»

> **Статус.** Живая дизайн-система — «MINIMAL STEEL»: стальной серый, бирюзовый акцент,
> Inter + JetBrains Mono, BEM, токены, две брейкпойнт-точки. Живёт в `src/styles/*.css`,
> подключается через `src/layouts/BaseLayout.astro`. Больше **ни один** файл не объявляет `:root`.
>
> Предыдущий «терминальный брутализм» (кремовый `#f5f5f0` + янтарный `#f5a623`, Roboto Condensed,
> инлайновые `<style is:global>` в каждой странице) **выведен из обращения**. Его спецификация — в
> истории git (`git show 8613a86:DESIGN.md`).

### Шрифт

| Роль | Гарнитура |
|---|---|
| Заголовки, текст, интерфейс | `--f-sans` = Inter Variable |
| Метки, кнопки, цифры, ID, микротекст | `--f-mono` = JetBrains Mono Variable |

Кириллица приходит из вариативных подключений `@fontsource-variable/*`. Condensed-гарнитуры нет —
Fira не устанавливалась и не нужна.

### Размер, отступ, раскладка

`--fs-9 … --fs-112` и `--sp-3 … --sp-72` — это **справочник по факту вёрстки, а не модульная шкала**.
Берём ближайшую существующую ступень, новых не изобретаем.

`--pad-x` (80 → 48 → 20) и `--sec-y` (140 → 96 → 72) переназначаются в двух медиазапросах — **это и
есть весь механизм адаптивных отступов**. Внутри секций padding руками не пишем.
`--content` = 1280, `--page` = 1440, `--nav-h` = 85.

Повторяющаяся арифметика раскладки: **760 + 48 + 472 = 1280**. Это ширины `.section__head-l`,
зазора и `.section__head-r` — и они же в тарифах.

## 3. Правила

Это критерии приёмки, а не пожелания.

1. **Только токены.** Ни одного сырого hex или px для того, что уже есть в `--c-*` / `--fs-*` / `--sp-*`. Смена палитры — правка одного файла.
2. **Две точки: 1024 и 768**, desktop-first, только `max-width`. Никаких `min-width`.
   Единственное исключение — навигация уходит в бургер на **1120**: ряд шириной 1073px физически не помещается между 1025 и 1072. Третья точка требует такого же замера, а не вкуса.
3. **Бирюза на светлом, мята на тёмном — и никогда наоборот.** `--c-teal` на `--c-ink` не проходит по контрасту. Тёмная секция инвертируется целиком: фон `--c-ink`, текст `--c-light`, вторичный `--c-muted-4`, линейки `--c-field`, акцент `--c-mint`. Инверсия уже описана одним блоком в `primitives.css` — дублировать её в секции не нужно.
4. **Ни теней, ни скруглений.** Глубина — тональная: карточка всегда на один тон отличается от своей подложки (`.section--bg` держит `.card`, `.section--white` — `.card--grey`). Потянулись за тенью — значит тон подобран неверно. Исключение по радиусу одно: `2px` на фотографиях.
5. **Количество карточек — это данные, а не CSS.** Никаких правок бордеров через `nth-child`, никакой вёрстки, которая знает, что элементов ровно восемь.
6. **Содержимое задаёт высоту.** `min-height`, но не `height`; никаких `vh` на блоках с текстом. Русский текст длинный — фиксированная высота ломается первой.
7. **`gap`, а не margin.** Отрицательных отступов нет.
8. **Ряды переносятся.** Больше двух детей во flex-ряду — ставим `flex-wrap`. `white-space:nowrap` на содержательном тексте запрещён; для составных токенов есть `.nowrap`.
9. **Абсолютное позиционирование — только для декора.**
10. **JS цепляется за `data-js`, а не за классы.** Рестайл не должен уметь сломать поведение.
11. **Никаких инлайновых `style=` в разметке.** Нужна ширина кнопки — есть `.btn--wide`.
12. **Тексты живут в `const`-массивах фронтматтера,** чтобы правка копирайта не трогала вёрстку.
13. **Новая секция — берём рецепт из §6.**

## 5. Компоненты (`components.css`)

`.nav` (+ announce, burger, panel) · `.subnav` · `.hero` (+ `__title--long`) · `.fact` · `.marquee` ·
`.quicknav` · `.tabs` · `.lesson` · `.module` · `.faq` · `.popover` · `.modal` (+ `__widget`, `.seg`) ·
`.streams-block` · `.student` · `.carousel` · `.pricing` · `.field` · `.verify` · `.footer` · `.subfooter`

**Хром страницы.** У главной — полноразмерная `.nav` с бургером и `.footer`. У подстраниц
(`/teams`, `/community`, `/verify`) — `.subnav` и `.subfooter`: ссылки главной навигации это
якоря, которые существуют только на `/`.

**Заголовки H1 — капсом**, через `text-transform` на `.hero__title` и `.verify__name`; в данных
строки остаются в смешанном регистре, чтобы их можно было отдать в `<title>` и `og:`. Две ступени:

| Класс | Кегль | Кому |
|---|---|---|
| `.hero__title` | 112 / 72 / min(46, 10.5vw) | Только `/` — короткая брендовая строка в два слова |
| `.hero__title` + `--long` | 60 / 48 / min(34, 8.2vw) | Подстраницы, где H1 это целое предложение |

Капс шире смешанного регистра примерно на 7%: на 112px заголовок `/teams` из-за этого уезжал
с двух строк на три с висячим словом. Отсюда вторая ступень. По той же причине у капса
распускается трекинг (`--long`: −2px → −1.2px) — у прописных нет выносных элементов, которые
поглощают плотный трекинг, и в кириллице −2px слипается. Ограничивать H1 своим `max-width` не
нужно: колонку уже держит `.hero__inner`, а лишняя рамка даёт рваный перенос.

## 6. Рецепт секции

```html
<section class="section section--bg" id="…" aria-label="…">
  <div class="section__inner">
    <div class="section__head">
      <div class="section__head-l">
        <p class="section__eyebrow">[метка] // Подпись</p>
        <h2 class="section__title">Заголовок <span class="section__title-mark">с акцентом</span></h2>
      </div>
      <div class="section__head-r section__head-r--tight">
        <div class="section__rule"></div>
        <p class="section__note">Пояснение.</p>
      </div>
    </div>
    <div class="grid-3"><!-- .card × N, из массива во фронтматтере --></div>
  </div>
</section>
```

Тональная пара обязательна: `.section--bg` → `.card`; `.section--white` → `.card--grey`.

## 7. Проверка

```bash
npm run build                                   # 33 страницы, без ошибок

npm run dev                                     # терминал 1
MSYS_NO_PATHCONV=1 node scripts/check-layout.mjs / /teams /community /verify
```

`check-layout.mjs` проходит 320 → 1920 (девять ширин) и падает на: горизонтальной обрезке,
любом display-элементе, чьё **самое длинное неразрывное слово** не влезает в свою колонку,
ошибках консоли и упавших запросах.

Две вещи про запуск:

- **`MSYS_NO_PATHCONV=1` обязателен в Git Bash**, иначе MSYS перепишет ведущий `/` в windows-путь.
- **Ложное срабатывание:** страницы с Яндекс.Метрикой всегда дают
  `ERR_CERT_AUTHORITY_INVALID` на `hdrc.yandex.net` (вебвизор) в headless Chromium. Судить по
  строкам `clipped` / `word too wide` / `scrolls horizontally` — их быть не должно.

Плюс к этому после каждой миграции: диф текста собранной страницы до и после (копирайт обязан
совпасть до символа), проверка гарнитур в девтулзах (никакой кириллицы в фолбэке, никакого
синтетического жирного) и прогон интерактива — аккордеоны, табы, модалки, `Escape`, снятие
блокировки скролла.
